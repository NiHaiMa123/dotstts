# ADR 0010：长音频训练素材预处理契约

- 状态：Accepted
- 范围：30–60 分钟音声、多角色/轻语/3D 麦混合素材

## 决策

长音频不是训练 utterance。它先进入独立、可恢复的 long-form 阶段，产生带源时间范围的 2–15 秒候选片段，之后才进入已有 catalog、质量、去重和冻结流程。

源文件始终只读。派生片段身份绑定源 SHA-256、源采样点范围、配置 SHA-256 和实现版本；同一输入可以确定性重建。解码必须分块，工作产物采用原子写入，启动时把残留 running 状态标记为 interrupted 并清理 partial 文件。

## 筛选边界

自动流程可以拒绝无法解码、空音频、非有限采样或不满足硬时长范围的技术失败。噪声、音乐、重叠人声、目标说话人偏离、轻语、耳语、角色音及空间音频均作为带证据的审核建议，不能在缺少校准和人工确认时静默进入训练集。

v1 只有 `normal` 可以成为自动保留建议；`soft` 与 `unknown` 必须复核；`whisper`、`roleplay`、`binaural_3d`、`singing` 和 `non_speech` 默认排除。默认排除仍保留候选记录，人工决定采用 append-only 方式覆盖建议，而不是删除证据。

ASR 仅产生候选文本和辅助边界。训练文本必须经过人工确认，ASR 不得覆盖人工文本。

## 双声道

检测前保留左右声道。只有声道能量、相关性和空间风险满足安全条件时才允许平均下混；否则选择更可靠声道或进入人工审核。不能对 3D/双耳素材无条件求平均。

## 配置

冻结配置为 `configs/lab/long_form/training_source_v1.yaml`。配置采用严格 Pydantic 校验，未知字段失败，输出目录不得位于只读 inbox 下，硬时长上限不得超过现有训练策略的 15 秒。

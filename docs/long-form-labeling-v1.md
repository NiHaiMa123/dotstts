# 长音频严格准入标注规范 v1

版本：v1（2026-09-13）。适用范围：LF-12 严格 gate 的参考包确认、开发集/留出集标注与人工复核。本规范定义分项标签；每条样本必须给出分项结论，不允许只有"保留/排除"。

## 1. 发声与角色标签（vocal_style）

每条样本只选一个主标签，存 `vocal_style`；与 `speaker_identity`（是不是目标演员）分开判定——同一演员的角色音不是 normal。

| 标签 | 定义 | normal 集处置 |
| --- | --- | --- |
| `normal` | 目标演员以日常说话声线、正常音量连续说话；允许句中自然语气词与普通换气 | 唯一可进训练集的标签 |
| `soft` | 整体音量显著低于该片正常说话、仍带完整声带振动的轻声 | 隔离，不进 normal |
| `breathy` | 气声主导：谐波成分明显减弱、气流声持续的说话方式 | 隔离 |
| `whisper` | 耳语：无声带振动的气声耳语，无论文字是否清楚 | 排除出 normal |
| `roleplay` | 角色音/夸张表演腔：故意压嗓、捏嗓、变调扮演，即使声纹相似 | 排除出 normal |
| `singing` | 唱、哼唱或明显旋律化发声 | 排除 |
| `non_speech` | 无语言内容或非语言发声主导 | 排除 |

### 呼吸与语气词的边界

- **普通换气**：句间自然的低强度吸气声，伴随正常台词 → 不单独构成排除理由。
- **表演性呼吸/刻意喘气**：作为表演内容的喘息、呻吟式呼吸 → `non_speech` 或 `roleplay` 处理。
- 语气词（"嗯""啊""好呢"）只要是有真实文字的自然语气，按文本原样保留；**纯**"嗯/啊/哈"且没有台词内容的片段标 `non_speech`。不按字表机械删词、不从词中间剪声音。

## 2. 空间标签（spatial_style）

| 标签 | 定义 |
| --- | --- |
| `mono_safe` | 原始 L/R 局部一致，可安全下混或本身就是单声道 |
| `nearfield_binaural` | 近讲/双耳效果：明显左右移动、单侧贴近或 Side 能量主导 |
| `spatial_unknown` | 空间证据不足或被 mono 处理掩盖 |

normal 集只接受 `mono_safe`。空间判定必须基于下混/增强前的原始 L/R 证据。

## 3. 事件标签（event_labels，多选）

| 标签 | 覆盖范围 |
| --- | --- |
| `slap_impact` | 拍击、碰撞、脆响等瞬态 |
| `friction` | 摩擦、衣物/布料窸窣、刮擦 |
| `bgm_music` | 背景音乐、歌曲片段 |
| `laugh_cry` | 笑、哭、尖叫等非台词发声 |
| `other_voice` | 第二个人声或其他人说话 |
| `foley_other` | 其他可辨拟音（水声、道具声等） |
| `breath_performance` | 表演性呼吸（区别于普通换气） |

normal 集要求 `event_labels` 为空；任何可信事件命中即触发 G5 gate。记录事件发生的源时间段，不只记录"有/无"。

## 4. 关键缺陷（任一成立即拒绝，不可补偿）

- 错人或非目标演员声线；同演员的角色音/耳语
- 可信的重叠语音或句内换人
- 可闻拟音、拍击、音乐残留（增强后仍存在的同样算）
- 台词文字错误、遗漏或异常重复；数字/专名/语气词实质分歧
- 切掉首尾字、辅音、齿音或尾音；非零边界滋声
- 增强损伤：水声、金属感、空洞、吞音节、台词被改变

高 SNR、高声纹相似度、长时长等指标一律不能抵消以上任一项。

## 5. 参考包确认规则

- 正常参考固定 6–12 条、每条 3–10 秒，覆盖不同语速/句调/源时间段；全部重新按本规范确认，旧"保留"结论不直接当真值。
- 难负例必须包含：`same_actor_roleplay`（同演员角色音）、`whispered_text`（有清楚文字的耳语）、`nearfield_binaural`（无明显左右移动的近讲/双耳声）、`event_over_speech`（人声清楚但夹拍击）。只用他人正常语音作负例不算覆盖。
- 新增标注每批不超过 12 条；参考选择计入新增标注总量。每批记录 batch_id、标注时间与本规范版本。

## 6. 拆分与验收纪律

- 参考集、开发集、留出集按 `configs/lab/long_form/split_v1.yaml` 整源隔离；相邻切片、raw/DFN3 对、重复规范化文本不跨拆分。
- 阈值只能在开发集上选择，冻结后在留出集验收一次；验收失败后改阈值必须换新留出证据，不反复查看同一留出集。
- 难负例用于能力测试，不冒充按真实分布抽取的通过集；样本不足时维持小批人工确认，不把反复抽查包装成 95% 置信保证。
